# krill/render

Renders a domain's `PRODUCT.md` and `product/*.md` files from krill's own
entities (`bazel run //krill/render/cmd:render`). This is the full detail
behind `AGENTS.md`'s "Generated-doc carve-out" — that section stays short
and always-loaded; this file is where the reasoning and the day-to-day rule
live.

## The carve-out

A domain whose product brief has been migrated into `krill/` (krill's
spec-of-record substrate, see [`krill/TOC.md`](../TOC.md)) has its
`PRODUCT.md` and `product/*.md` files rendered by `krill/render`, not
hand-authored. **These files are non-hand-editable** — every heading,
load-bearing decision, capability, and milestone in them is a projection of
krill's own entities, computed fresh on every render (krill's LB5: krill
owns an FR's identity; a rendered file is a projection with provenance,
never a second writable source). Each such file carries a `GENERATED by
krill/render` header naming the entity and the render revision it came
from, so the marker is visible at the point of editing, not just here.

**A hand edit to one of these files is silently lost the next time the
domain re-renders** — there is no reconciliation step and no diff review of
the overwrite, per LB5's "the reverse direction is unpickable" reasoning. To
change one of these files: edit the underlying entity in krill (via krill's
write API or MCP surface, gated by `init` per krill's FR3) and re-run the
renderer, never `Edit`/`Write` the committed file directly.

## Scope

This carve-out is narrow: it applies only to a domain's own
`PRODUCT.md`/`product/*` once that domain's brief lives in krill (today,
only `krill/` itself, per krill's own M1 self-hosting milestone). Every
other domain's `PRODUCT.md` remains the ordinary
hand-authored-via-`/project-manager:product` document `AGENTS.md`'s
Documentation Conventions describe, and `ARCHITECTURE.md`/`README.md`/
`ENV.md`/`TOC.md` stay hand-written even for a krill-migrated domain —
krill's own non-goals scope its renderer to the product doc set only (see
`krill/PRODUCT.md`'s Non-goals).
